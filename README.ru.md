## Зачем ScsDrive?

ScsDrive — лёгкий инструмент для Windows, который монтирует WebDAV, NAS и удалённое хранилище как локальные диски — используйте облачные файлы как локальную папку.

## Основные функции

Просто, стабильно, без лишних хлопот.

- **Монтирование в один клик** — Введите адрес WebDAV и учётные данные, чтобы подключить как локальный диск. Не нужно подключаться вручную каждый раз.
- **Нативный опыт** — Просматривайте, редактируйте и перетаскивайте файлы как локальную папку. Приложения читают/пишут напрямую.
- **Автозапуск** — Автоматическое переподключение при загрузке. Всегда доступно, без ручных действий.
- **Лёгкий и стабильный** — На зрелом ядре. Низкое потребление ресурсов, стабильная долговременная работа.
- **Несколько серверов** — Подключайте несколько WebDAV / NAS одновременно. Независимые буквы дисков, без конфликтов.
- **Безопасное соединение** — Шифрованное HTTPS-соединение. Учётные данные хранятся безопасно.
- **Подключение без пароля** — Подключение, в том числе при запуске, не требует пароля, диск виден. Без сохранения каждый вход спрашивает один раз; вышли и зашли снова — ещё раз.

## Частые вопросы

**Какие WebDAV-сервисы поддерживает ScsDrive?**  
Поддерживает любой стандартный WebDAV-сервис, включая собственные NAS (Synology, QNAP и др.), Nextcloud, Nutstore и другие.

**В чём разница между пробной и лицензионной версией?**  
Функции те же. Пробный период 7 дней; с кодом друга — 14. Если кто-то начнёт пробный период с вашим кодом, вы тоже получите +7 дней без ограничения. Бессрочные лицензии дни не добавляют. После окончания нужна лицензия.
