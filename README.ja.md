## ScsDrive を選ぶ理由

ScsDriveは軽量なWindowsツールで、WebDAV、NASなどのリモートストレージをローカルドライブ文字としてマウントし、ローカルフォルダのようにクラウドファイルを操作できます。

<p align="center">
  <img src="docs/hero.png" alt="ScsDrive hero" width="920">
</p>

## 主な機能

シンプル、安定、手間いらず。

- **ワンクリックマウント** — WebDAVのURLと認証情報を入力するだけでローカルドライブとしてマウント。毎回手動で接続する必要はありません。
- **ネイティブ体験** — ローカルフォルダのように閲覧、編集、ドラッグ可能。アプリが直接読み書きできます。
- **自動起動** — 起動時に自動的に再接続。手動操作不要で常に利用可能。
- **軽量・安定** — 成熟したカーネルを採用。低リソースで長時間安定して動作します。
- **マルチサーバー** — 複数のWebDAV / NASサービスを同時にマウント可能。独立したドライブ文字で干渉しません。
- **安全な接続** — HTTPS暗号化接続に対応。認証情報は安全に保存されます。
- **パスワードなしで先に接続** — 接続も起動時の自動接続もパスワード不要で、ドライブは見えたままです。保存しない場合は入るたびに一度入力し、出てから再入室するとまた入力します。

**ScsDriveはどのWebDAVサービスに対応していますか？**  
標準WebDAVプロトコルをサポートするすべてのサービスに対応。自宅NAS（Synology、QNAPなど）、Nextcloud、Nutstoreなど。
